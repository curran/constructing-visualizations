Fork starter repository , modify the "Week 1" assignment in some creative way, and deploy it to GitHub pages.

Fork the Starter

For the assignments in this course, we'll use a single GitHub repository containing the assignments.

To get started, fork this repository in GitHub: https://github.com/curran/data-visualization-student-starter

Edit the Code

The main purpose of this assignment is to prove that you can edit and deploy front end code, which is the basis for the course.

First of all, you'll need to have Git and NodeJS installed locally. I'd recommend NVM for installing NodeJS. After cloning the repository, you can run it locally with `npm install`, then `npm run dev`.

After cloning the repository, modify the code under `src/assignments/week-01` in some way. It could be very minor, like changing the color of the circles, or it could be more than that, maybe changing the cricles to lines or rectangles, or creating somr sort of creative graphics or illustration. Minimal changes will get full marks. Use this as an opportunity experiment, have fun, and demonstrate your level of front end development ability coming into the course.

You can use `npm run prettier` to auto-format your code.

Definitely use some sort of AI coding agent. I'd recommend Pi Agent on OpenRouter / deepseek-v4-flash. Or if you already have Claude Code, Codex, or GitHub Copilot, those work great too.

Deploy the App in GitHub Pages

The starter repository is set up to deploy to GitHub Pages. Some minor changes may be needed to adjust for the new repository name, if you change it. You may need to go into repository settings to get it to work. The goal is to have a shareable link that points to your code running, hosted by GitHub Pages.

For example, the repository https://github.com/curran/constructing-visualizations is hosted at https://curran.github.io/constructing-visualizations/ . Your starter repo fork should mirror this, under your own GitHub account.
