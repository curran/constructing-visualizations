Find a concrete dataset related to your project ideas, load it in the front end, and display a summary of it.

Find a Dataset

Research public datasets available related to a topic that interests you. Find a public dataset that you can download and get into a CSV or JSON file less than 8MB. Put that file somewhere in the `public` directory of your Vite app created last week, for example `public/data/dataset-a`, replacing `dataset-a` with the name of your dataset. Add a `README.md` file in that same subdirectory, which documents the dataset, including where it was downloaded from and the overall concept of it. Be sure to include an analysis of the attributes (for each attribute, say whether it's "Categorical", "Ordinal", "Quantitative", or some special case of space (geo ID, lat/long) or time (date, timestamp, time interval).

Load and Summarize the Dataset

Develop a new entry in your project repository called "Week 2", containing front end code that loads, parses, and displays a summary of your dataset, such as row and column count. A minimal representation is fine, but if you want to, you can explore more advanced representations such as summary stats, listings of unique values, or even some type of visualization. The goal here is to prove you can get the data onto the page in some form.
